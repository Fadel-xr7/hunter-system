# بوت تيليجرام لنظام سولو ليفلنق

ترسل للبوت مهمة بسطر واحد، فيرد عليك برابط. تضغط الرابط، يفتح الموقع ويسألك: تضيفها؟

```
مهمة: مراجعة الكود الساعة 10 مساءً !A #ذكاء
تمرين ضغط يومي الساعة 6 ص #قوة
بوابة: تسليم التقرير بكرة الساعة 9:30 ص !S
```

## التشغيل لأول مرة

1. في تيليجرام افتح **@BotFather**، أرسل `/newbot`، واختر اسم البوت. بيعطيك **توكن**.
2. داخل مجلد `bot` انسخ `.env.example` وسمِّ النسخة `.env`، وحط التوكن بعد `TELEGRAM_BOT_TOKEN=`.
3. افتح Terminal في VS Code داخل مجلد `bot` وشغّل:
   ```
   uv run bot.py
   ```
4. أرسل `/start` للبوت. بيعطيك رقمك؛ حطه في `.env` بعد `ALLOWED_USER_ID=`، ثم أوقف البوت (Ctrl+C) وشغّله مرة ثانية. كذا البوت يرد عليك أنت بس.

## ملاحظات

- البوت يشتغل ما دام الـ Terminal مفتوح وجهازك شغال.
- لو `SITE_URL` محلي (`127.0.0.1`)، الرابط يفتح على جهازك فقط، ويطلع كنص بدل زر لأن تيليجرام يرفض الأزرار المحلية.
- عشان يفتح من الجوال: ارفع الموقع على GitHub Pages وغيّر `SITE_URL` لرابط `https://...`، وبيطلع لك زر "أضفها للنظام".
- لا ترفع ملف `.env` على GitHub، وموجود في `.gitignore`.
